# LangChain LLM PoC

This is a proof of concept for integrating LangChain with a large language model (LLM) to demonstrate its capabilities and potential use cases.

## Setup project locally

1. Clone the repository:
   ```bash
   git clone
    cd langchain-llm-poc
    ```

2. Create a virtual environment:
    ```bash
    python3 -m venv .venv; source .venv/bin/activate
    ```

3. Install the required packages:
    ```bash
    poetry install
    ```

4. Run the application:
    ```bash
    poetry run python3 main.py
    ```
